# Student Performance Prediction Using Machine Learning

## Project Overview
This is a Python mini project that predicts a student's final examination score using a machine learning regression model. It uses student-related information such as study hours, attendance, previous scores, sleep hours, extracurricular participation, and parental support.

The project generates a **synthetic dataset** in Python for demonstration and model training. It does not use real student records or an external dataset.

## Objectives
- Generate sample student performance data.
- Prepare numerical and categorical data for machine learning.
- Train a Random Forest Regression model.
- Evaluate the model using RMSE and R² score.
- Predict a final examination score for a sample student profile.

## Technologies and Libraries
- Python
- NumPy
- Pandas
- Scikit-learn

## Dataset Description
The dataset is generated by the `generate_synthetic_data()` function in the Python program. The `main()` function generates 1,500 records.

| Feature | Description | Data type |
|---|---|---|
| Study_Hours | Hours spent studying | Numerical |
| Attendance | Attendance percentage | Numerical |
| Previous_Scores | Previous academic scores | Numerical |
| Sleep_Hours | Hours of sleep | Numerical |
| Extracurricular | Participation (Yes/No) | Categorical |
| Parental_Support | Support level (Low/Medium/High) | Categorical |
| Final_Score | Final examination score to predict | Numerical target |

The final score is created from the input features with added random noise and is limited to the range 0–100. Because the data is synthetic, the results are for learning and demonstration only.

## Project Workflow
1. Generate the synthetic student dataset.
2. Separate the input features (`X`) and target (`y`).
3. Split the data into training and testing sets (80% training and 20% testing).
4. Scale numerical features using `StandardScaler`.
5. Encode categorical features using `OneHotEncoder`.
6. Combine preprocessing and `RandomForestRegressor` in a Scikit-learn pipeline.
7. Train the model on the training data.
8. Evaluate predictions using RMSE and R² score.
9. Predict the score for an example student profile.

## Machine Learning Algorithm
**Random Forest Regression** is used to predict the numerical final examination score. The model uses 100 decision trees (`n_estimators=100`).

## Model Evaluation
The program prints:
- **RMSE (Root Mean Squared Error):** measures the typical size of prediction errors; lower is better.
- **R² score:** indicates how well the model explains variation in the target values; a value closer to 1 is generally better.

The exact values are displayed when the program runs. They may vary if the code, data generation, or software environment changes.
